1. Nyalakan Saklar MCB
(gc chapel 1.jpg)
Nyalakan saklar mcb satu persatu dimulai dari:
Master
Projector
Sound + PC
Fresnel


2. Nyalakan Power Sequencer 
(gc chapel 2.jpg)
Tekan tombol power



3. Nyalakan PC Chapel 
(gc chapel 3.jpg)
Tekan tombol power


4. Nyalakan LCD menggunakan remote
(gc chapel 4.jpg)

# CARA MEMATIKAN FOH CHAPEL di GMS SURABAYA PUSAT UTARA

1. Matikan LCD menggunakan remote
(gc chapel 5.jpg)


2. Shutdown PC Chapel
(gc chapel 6.jpg)
Tekan tombol Windows di pojok kiri bawah layer
Lalu tekan tombol power diatas tombol Windows
Kemudian tekan tombol bertuliskan “Shut down”
Komputer akan mati


3. Matikan Power Sequencer 
(gc chapel 2.jpg)


4. Matikan Saklar MCB
(gc chapel 1.jpg)
Matikan saklar satu-persatu dari kanan ke kiri, dimulai dari saklar:
Fresnel
Sound + PC
Projector
Master
